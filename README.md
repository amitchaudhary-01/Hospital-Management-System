# 🏥 Hospital Management System

A full-stack **Hospital Management System** built using the MERN stack (MongoDB, Express.js, React, Node.js) designed to streamline hospital operations, manage patient appointments, and handle role-based workflows for patients, doctors, and administrators.

## 🚀 Features

* **Patient Portal:** Create accounts, browse specialist doctors, and book/manage appointments.
* **Doctor Portal:** View assigned appointments, update appointment status, and manage patient care.
* **Admin Dashboard:** Oversee hospital operations, manage user accounts, and create/manage doctor profiles.
* **Interactive UI:** Responsive and modern user interface styled with **Tailwind CSS** and enhanced with **AOS animations**.

## 🛠️ Tech Stack

* **Frontend:** React.js, JavaScript, Tailwind CSS, AOS Animation
* **Backend:** Node.js, Express.js
* **Database:** MongoDB

## ⚙️ Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing.

### Prerequisites

Make sure you have the following installed on your system:
* [Node.js](https://nodejs.org/) (v14 or higher)
* [MongoDB](https://www.mongodb.com/) (Local or Atlas connection string)

### Installation & Setup

1. **Clone the repository**
   ```bash
   git clone [https://github.com/amitchaudhary-01/Hospital-Management-System.git](https://github.com/amitchaudhary-01/Hospital-Management-System.git)
   cd Hospital-Management-System

2.  **Usage**
   Open your browser and navigate to the frontend URL (usually http://localhost:5173 or 3000).

Register as a Patient to book appointments, or log in with an Admin account to manage doctors and system settings.
